# Sanitized portfolio screenshots

These images are prepared for public freelance profiles.

- Browser tabs, addresses, domains, IP addresses, avatars, and browsing context were removed.
- Russian interface copy was replaced with English copy.
- Names, organizations, locations, dates, balances, quantities, prices, counts, permissions, and usernames are fictional mock data.
- CRM images use a neutral demo workspace.
- ERP images use the fictional brand Northstar Operations.
- The images must not be described as current production data or real customer results.
